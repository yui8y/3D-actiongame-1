# AI横断型ゲーム開発司令室
AIを活用したゲーム開発の進め方を、GitHub上で管理・公開するプロジェクトです。
Unity(C#)で、タイトル→プレイ→リザルトの流れを持つ小型アクションゲームを制作します。

## 目的
- AIを「使いこなす」開発フローの実績づくり
- Issue / Pull Request を使ったチーム開発の流れの実践

## 使用AIと役割
| AI | 役割 |
|---|---|
| Claude | 企画補助、設計、実装、デバッグ |
| (今後追加予定) | コードレビュー |

## 進め方
1. Issueでタスクを管理する(GitHub Projects)
2. 1タスク=1ブランチ=1PRで進める
3. AIの活用内容は `docs/ai-log/` に記録する

## 開発環境
- Unity: Unity6.6(6000.6.5f1)
- 言語: C#
